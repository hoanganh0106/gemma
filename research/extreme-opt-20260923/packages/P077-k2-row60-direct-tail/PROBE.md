# P077 K2 split weight transfer probe

Parent P041 with the P036 60-row two-transfer projection, retaining P041's direct tail DMA. The intended overlap was second weight DMA with first Main contraction. Compiler SDK 0.8.1 accepted the code. Whole-K2 schedule increased from P041 21,290 / 42 instructions to 22,816 / 56. First weight DMA 1,936-8,902; first Main contract 8,902-9,796; second weight DMA 8,902-15,868. Only 894 cycles of Main/DMA overlap are exposed, while the two weight loads and split commands increase cost. No fixture or hardware result exists for this probe; do not promote. For this 60/60 geometry, removing all non-overlapped command overhead would still require more than the observed overlap to reach P041. The architectural goal of streamed weights is not disproved by this implementation.
