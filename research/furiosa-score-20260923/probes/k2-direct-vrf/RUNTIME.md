# K2 direct VRF: current-fixture runtime validation

**All four jobs in the bounded A1–B1–B2–A2 comparison succeeded, with 60/60 output comparisons passing across all three kernels and three independently seeded runs per job.** K2 cycles decreased in both pairs: 0.371% for B1/A1 and 1.980% for B2/A2. Their geometric mean cycle ratio is **0.988212**, an observed **1.1788% reduction**. Two pairs provide promising evidence, but a stable hardware speedup is **not established**, and the candidate is not promoted to main source.

Only `src/device/sliding/output31.rs` differs from the current baseline source. The change moves inverse RMS directly from the Main pipeline into VRF, removing the DM commit and Sub reload. K1/K3 and the public test harness are identical to baseline. Source identities for all 53 source files and the selected Cargo executable artifact are stored in `runtime-manifest.json`; `candidate.patch` contains the complete source delta. Main repository source was not modified or promoted.
